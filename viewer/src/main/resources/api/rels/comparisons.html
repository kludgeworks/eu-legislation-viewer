Finds the comparison of the act's text in one language between the law on two days. The answer redirects to the comparison of the versions that apply on the two days. The comparison lists its differences.

The link is a template with these query parameters:

from
The first day.
to
The second day. It must not be before from.
language
The language. For example, eng.
amendingAct
Optional. The CELEX number of an act. The comparison then shows only the changes of that act.

If from, to or language is missing, or from is after to, the status is 400 Bad Request. If the texts are not ready yet, the answer is 202 Accepted. See Waiting.
