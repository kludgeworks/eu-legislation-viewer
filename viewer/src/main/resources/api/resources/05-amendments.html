Amendments

The changes that other acts made to the provisions of an act, as the Publications Office records them. It links to the act, up.

Members

amendments

Each change. It has:

act
The CELEX number of the amending act.
cited
How the Official Journal cites the amending act. For example, 2019/103.
location
Where it acts, as the Publications Office codes it. For example, AN PO 8.1.2.3 PTA (c).
role
What it did: replacement, addition, deletion, repeal, amendment, extension, suspension, deferral or other.
from
The day from which it applies. Null if the Publications Office has none.
until
The day on which it ends, for a change that lapses. Null for the others.
languages
For an act that corrects only some languages: those languages. Empty if it changes all of them.
dates

The dates of each amending act, by its CELEX number. Each date has:

date
The day. Null if the Publications Office has a placeholder or a date that cannot be.
kind
entry_into_force, application, taking_effect or transposition: the day from which the Member States apply a directive.
forPart
Whether it is for a part of the act only.
clause
What sets it, as the Publications Office writes it. For example, DATPUB +20 V ART 2.
