Outline

The outline of a text: the occurrences that have a title, in order. These are the articles, the annexes, the divisions, and the levels of an annex that have a heading. It links to the text, up, and to an occurrence by its eId, av:occurrence.

Members

entries

The outermost occurrences. Each has:

eId
Its eId. For example, art_3.
kind
What it is. For example, article.
num
Its number as printed. For example, Article 3. Empty if it has none.
heading
Its heading. Empty if it has none.
entries
The occurrences below it.
