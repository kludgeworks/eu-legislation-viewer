The law on a day

The versions of an act that apply on a day. Usually one version applies. On a day on which an original text and a consolidated version apply in different languages, both apply.

If the day is before the first version, the answer is the problem before-first-version.

Members

date
The day asked.
until
The day on which the next version starts. Null if no version starts later.
divergences

Where the text of the versions is not the law on the day. Each has:

kind
late: the act applies, but the text does not include it. early: the text is included, but the act does not apply yet.
act
The CELEX number of the act.
cited
How the Official Journal cites it. For example, 2017/815.
appliesFrom
The day from which the act applies.
includedIn
The first version that includes its text: oj, or its date. Null for a late text that no version includes yet.
languages
The languages whose text differs. An amending act can change the text of some languages only.

The versions that apply are in _embedded, as av:version. The answer links to the act, up.
