The law on a day

The versions of an act that apply on a day. Usually one version applies. On a day on which an original text and a consolidated version apply in different languages, both apply.

If the day is before the first version, the answer is the problem before-first-version.

Members

date
The day asked.
until
The day on which the next version starts. Null if no version starts later.
divergences

Where the text of the versions is not the law on the day. Each has:

kind
pending: a pending amendment. The act applies, but the text does not include it. prospective: a prospective amendment. The text includes it, but the act does not apply yet. undated: an undated pending amendment. The act is in force and the text does not include it, but Cellar does not give the day from which it applies.
act
The CELEX number of the act.
cited
How the Official Journal cites it. For example, 2017/815.
appliesFrom
The day from which the provisions in places apply. If places is empty, the day from which the whole act applies. Null for an undated one.
includedIn
The first version that includes its text: oj, or its date. Null for a pending amendment that no version includes yet, and for an undated one.
places
The provisions that the act changes and that are pending or prospective, in the order of the text. Each has a location, as Cellar gives it, and a name, for example point 4.1.3.3. Empty if the texts do not tell which provisions; then the act is compared as a whole.
languages
The languages whose text differs. An amending act can change the text of some languages only.

The versions that apply are in _embedded, as av:version. The answer links to the act, up.
