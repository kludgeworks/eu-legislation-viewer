Version

A version of an act: its original text, or a consolidated version. A version applies from its date until the date of the next version.

Members

version
Where it is among the versions: oj for the original text, or the day from which it applies.
kind
original or consolidated.
date
The day from which it applies.
celex
The CELEX number of the document that holds its text.
interim
Whether the Publications Office can still revise it.
integrates
The CELEX numbers of the acts that the Publications Office consolidated in this version.
languages
The languages in which the viewer can show its text, by the EU's codes.

Links

up
The act.
version-history
The list of the versions of the act.
predecessor-version
The version before it. Absent for the first version.
successor-version
The version after it. Absent for the latest version.
av:text
Its text, one link for each language. The hreflang of the link gives the language.

The list of versions, version-history, has each version in _embedded.item, the first one first. It links to the act, up, to the first version, first, and to the latest version, latest-version.
