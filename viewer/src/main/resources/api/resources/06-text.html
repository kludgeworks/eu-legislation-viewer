Text

The text of a version in one language. Its JSON Schema is text.schema.json.

The viewer makes a text the first time that someone asks for it. Until the text is ready, the answer is 202 Accepted. See Waiting. If the viewer cannot make the text, the answer is the problem text-failed.

Members

version
Where the version is among the versions: oj, or its date.
celex
The CELEX number of the document that holds the text.
language
The language, by the EU's code. For example, eng.
text
The text, in its parts, as the Official Journal prints it: title, preamble, body, conclusions, annexes and notes. A part that the text does not have is not in the answer. title is running text. notes is a list of footnotes, each with its eId, its marker and its blocks. Each other part is a list of blocks.

Links

up
The version.
alternate
The text in each other language of the version. The hreflang of the link gives the language.
av:outline
The outline of the text.
av:occurrence
A occurrence of the text, by its eId. A template with one variable, eId. For example, art_3 or anx/pnt_1.2.
av:preparation
The preparation of the texts of the act in the language.
describedby
The JSON Schema of the answer.

Blocks

The type of a block tells what it is:

text
A paragraph of running text.
occurrence
An article, a paragraph, a point, an annex and so on. It has an eId, a kind, and its blocks in content. It can have a num, a heading and a subheading. The list of kinds can grow.
table
A table, in rows of cells. A cell holds blocks, because a cell can hold occurrences.
figure
An image, by the name of its file.
quotation
Text that an amending act quotes. It is not law of the act that quotes it.
deleted
Blocks that an amendment deleted, which the consolidated version still shows. They are not in force.

A block that a consolidation changed has amendedBy: the amending act, by its CELEX number, and what it did.

Running text

Running text has two forms. text is plain text. It does not have the markers of notes or the words that an amendment deleted. html is HTML with only these elements:

  • b, i, u, s, sup, sub, and span with a class, for typefaces.
  • time, with datetime, for a date.
  • cite for a reference to the Official Journal, and a for a link. The marker of a note links to # and the note's eId.
  • span with data-act and data-action for words that an amending act changed, and s with them for words that it deleted.
  • ins and del for the words that a comparison marks.
  • br, span with lang, img, and math in MathML.
