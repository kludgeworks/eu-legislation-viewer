Root

The start of the API, /api. It has only links.

Links

av:act
An act, by its CELEX number. A template with one variable, celex. For example, 32015R1998 or 12016E/TXT.
av:act-by-celex
Finds an act by a CELEX number, in the query parameter celex. The answer redirects to the act. The CELEX number of a consolidated version redirects to that version. For example, 02015R1998-20260322.
av:act-by-eli
Finds an act by its ELI, in the query parameter eli. For example, reg_impl/2015/1998. The answer redirects to the act.
