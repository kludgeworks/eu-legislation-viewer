Occurrence

An occurrence of a text, by its eId, with all its content and the footnotes that it refers to. Its JSON Schema is occurrence.schema.json. If the text has no such occurrence, the status is 404 Not Found.

Members

occurrence
The occurrence, as a block of the text.
footnotes
The footnotes that the occurrence refers to, in the order of the text. Absent if there are none.

Links

up
The text.
