Comparison

The comparison of the text of an act in one language between two versions. It lists each provision that changed. To get it, fill in the template av:comparisons of the act:

${comparisons/lookup}

If a text is not ready, the answer is 202 Accepted. See Waiting.

Members

from
The first day of the earlier version.
to
The first day of the later version.
language
The language, by the EU's code. For example, eng.
amendingAct
The act whose changes the comparison is limited to. Null if it is not limited.
withoutPreamble
earlier or later: the text that has no preamble while the other has one. The comparison then does not compare the preambles. Null if both or neither have one.

The differences are in _embedded.item, in the order of the text. Each has the members of a difference except before, after, changes and shown, and a link to the difference, self.

Links

up
The act.
av:difference
A difference, by the eId of its unit. A template with one variable, eId.
