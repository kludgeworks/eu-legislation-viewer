Act

An EU act, by its CELEX number.

Members

celex
Its CELEX number.
eli
The path of its ELI. For example, reg_impl/2015/1998. Older acts have none.
type
Its resource type, as the code of the Publications Office. For example, REG_IMPL.
titles
Its title in each language that the Publications Office has, by the EU's code of the language. For example, eng.
dateOfDocument
The day on which it was adopted or signed.
inForce
Whether it is in force, as the Publications Office records it.
endOfValidity
The day on which it stops to apply. Null if it has no end.

Links

version-history
The list of its versions.
latest-version
Its latest version.
av:on
The law on a day. A template with one variable, date. For example, 2022-02-14.
av:amendments
The amendments of its provisions.
av:comparisons

Finds the comparison of its text in one language between the law on two days. The answer redirects to the comparison of the versions that apply on the two days. A template with these query parameters:

from
The first day.
to
The second day. It must not be before from.
language
The language. For example, eng.
amendingAct
Optional. The CELEX number of an act. The comparison then shows only the changes of that act.

If from, to or language is missing, or from is after to, the status is 400 Bad Request.
