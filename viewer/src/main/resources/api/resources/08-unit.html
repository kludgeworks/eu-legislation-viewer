Unit

A unit of a text, by its eId, with all its content and the notes that it refers to. Its JSON Schema is unit.schema.json. If the text has no such unit, the status is 404 Not Found.

Members

unit
The unit, as a block of the text.
notes
The notes that the unit refers to, in the order of the text. Absent if there are none.

Links

up
The text.
describedby
The JSON Schema of the answer.
