History

The history of an act, by its changes to the text in one language: the state of the act itself for each day, and the state of each act that amends it. An amending act can change the text of some languages only, so the history is of one language. It links to the act, up.

Members

state

The states of the act itself, as periods in order. Each has:

from
The first day of the period. Null if it has no start.
until
The first day of the next period. Null if it has no end.
value
The state of the act in the period, as in the history on a day.
amendingActs

Each amending act, newest first. Each has:

celex
Its CELEX number.
state
Its state as a whole, as periods in order. The value of a period is the code of the state.

Links

av:on
The history on a day. A template with one variable, day. For example, 2022-02-14.
${act/history}

The history on a day

The same history, read for one day. It links to the history, up.

day
The day asked.
state

The state of the act itself on the day, with the facts that give it. A fact that does not belong to the state is null. It has:

state
not_in_force: the act is not in force yet. not_applying: the act is in force, and it does not apply yet. in_part: the act applies in part. applies: the act applies. no_longer_in_force: the act is no longer in force. not_known: the data does not tell the state.
entryIntoForce
The entry into force, for an act that is not in force yet.
appliesFrom
The day from which the act applies, if it applies from one day.
appliesInFullFrom
The day from which the whole act applies, for an act that applies in part.
endOfValidity
The end of validity, for an act that is no longer in force.
repealedBy
The CELEX numbers of the acts that repealed it.
notKnownBecause
Why the data does not tell the state. For example, a_clause_sets_the_day.
amendingActs

Each amending act, newest first, as it stands on the day. Each has:

celex
Its CELEX number.
state
Its state as a whole, as a code of the states above.
applies
How many of its changes apply.
notApplying
How many of its changes do not apply yet.
notKnown
How many of its changes have a state that the data does not tell.
changes
How many changes it makes to the text in the language.
